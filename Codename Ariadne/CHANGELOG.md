- Documented the current prototype boundary and the production controls still required before real data is permitted.

- Verified packaged UDS mode `0600` inside a `0700` directory, zero TCP listeners, stripped inherited probe state, no credential markers, exit 0 AppleEvent shutdown cleanup, and exit -9 parent-kill cleanup.

The local overlay resolves only the spike; production requires one Developer ID across embedded libraries and Tauri before notarisation and clean-machine validation.
- Kept raw vault keys out of argv, environment, bootstrap, HTTP, logs, files, generated contracts, and webview state; the packaged sidecar now proves inherited anonymous FD-198 delivery through PyInstaller.
- Re-check lease authorization immediately after Keychain retrieval and before `GRANT`; delayed-custodian coverage proves system lock revokes a late result, kills the old sidecar, and restarts locked.

- Enforce profile isolation at API, repository, and composite-foreign-key layers, and use request-local zeroised fingerprint subkeys and idempotency HMACs.
